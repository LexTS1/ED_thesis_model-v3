# Archetype Parameters Merged v2

This table is the authoritative runtime archetype table for `model_v3`.

The current revision incorporates the local DeepSearch evidence note
`DeepSearch/Empirical grounding for Belgian residential archetypes.md`.
Only parameters with directly usable evidence were changed. Parameters that
still require extra reconstruction or calibration are left explicit in the
uncertainty notes rather than silently treated as empirical facts.

It merges:

- stock identity and geometry from `archetype_parameters_v1.csv`, updated where
  possible with Belgian Census 2021 dwelling-type shares and Belgian TABULA
  floor-area evidence
- dynamic-capacitance classes from the legacy v1.4 archetype set
- airflow/control semantics from the legacy v1.5 archetype set, updated where
  possible with Belgian measured ACH50 anchors
- internal-gain and solar defaults from the v1.3 configuration and the two design PDFs

## Merge rules

- `archetype_id`, dwelling class, renovation state, and setpoints come from the
  earlier runtime archetype set.
- `stock_weight` now uses official occupied conventional dwelling-type shares
  from the Census 2021 evidence in the DeepSearch note:
  detached `16.2%`, semi-detached/open `13.7%`, closed/terraced `24.2%`, and
  apartments `45.5%`. Because the reviewed evidence did not provide a direct
  as-is/renovated split, the previous within-type as-is/renovated split is
  preserved.
- `floor_area_m2` now uses Belgian TABULA representative type means from the
  DeepSearch note: detached `185 m2`, semi-detached `143 m2`, terraced `130 m2`,
  and apartment `100 m2`. `volume_m3` is recomputed as floor area times the
  existing `2.5 m` ceiling-height assumption.
- `UA_W_per_K` and `H_W_per_K` are rebuilt from
  `envelope_archetypes_v1.csv`, which reconstructs opaque-wall, window, roof,
  and floor areas before applying state-specific U-values. The reconstruction is
  generated by:

  ```bash
  python3 -m model_v3.building.rebuild_archetype_envelope \
    --repo-root . \
    --print-summary
  ```

  The envelope reconstruction uses the Belgian TABULA/EPB anchors in the
  DeepSearch note where directly available, and uses existing repository
  `config/archetypes.yaml` old-stock floor/window defaults where the
  DeepSearch note did not provide direct values. The values are more traceable
  than the previous aggregate UA/H constants, but remain archetype-level
  assumptions because exact external wall/window/roof/floor areas are not
  observed.
- `C_J_per_K` is mapped by explicit dwelling-type and renovation rule:
  - detached as-is -> `lightweight` class (`5e6 J/K`)
  - detached renovated -> `medium` class (`1e7 J/K`)
  - semi-detached or terraced as-is -> `medium` class (`1e7 J/K`)
  - renovated semi-detached, renovated terraced, and all apartments -> `heavy` class (`2e7 J/K`)
- `thermal_mass_kWh_per_K` and `thermal_mass_Wh_per_C` are direct conversions from `C_J_per_K`.
- `occupants_per_dwelling` remains `2.0` in the static archetype table as the
  reference value. Stochastic cohort runs now override it with sampled household
  sizes from the configured household-size distribution.
- Internal gains use the v1.3 reference defaults:
  - `away = 0 W/person`
  - `awake = 70 W/person`
  - `sleep = 60 W/person`
  - `appliances = 0.70`
  - `lighting = 0.85`
  - `cooking = 0.50`
  - placeholder `3 W/m²`
- Solar defaults use the v1.3 reference structure:
  - `glazing_ratio = 0.16`
  - `g_value = 0.77` for as-is and `0.63` for renovated stock
  - `frame_fraction = 1.0` because `glazing_ratio` is interpreted as glazed-area fraction rather than opening-area fraction
  - `dirt_factor = 0.95`
  - `incidence_factor = 0.90`
  - `shading_factor = 0.77`
  - orientation shares `N/E/S/W = 0.20 / 0.25 / 0.35 / 0.20`
- Airflow defaults use Belgian measured airtightness anchors from the DeepSearch
  note and the previous v1.5 ventilation semantics:
  - as-is stock uses `ACH50 = 6.3`, `ACH_inf = 6.3 / 20`, `natural`, `ACH_vent_base = 0.2`, `ACH_vent_occupied = 0.5`
  - renovated stock uses `ACH50 = 2.5`, `ACH_inf = 2.5 / 20`, `mechanical_extract`, `ACH_vent_base = 0.2`, `ACH_vent_occupied = 0.3`
  - `eta_HRV = 0.0` for all rows because no balanced-MVHR upgrade is inferred unless explicitly encoded by source data

## Important caveat

The update improves the empirical grounding of dwelling-type weights, floor
areas, ACH50 anchors, and envelope UA traceability. It does not make every
column empirically strong. Renovation-state shares, exact envelope geometry,
within-age U-value variation, ACH50-to-natural-infiltration conversion,
ventilation prevalence, thermal capacitance, setpoint schedules, solar factors,
and internal-gain fractions remain assumptions or archetype-level
approximations. They should be treated as sensitivity-analysis parameters rather
than measured Belgian dwelling properties.

## Envelope reconstruction v1

`envelope_archetypes_v1.csv` is the auditable intermediate table behind the
runtime `UA_W_per_K` and `H_W_per_K` values. It records:

- the assumed number of storeys;
- footprint, perimeter, gross wall area, exposed wall area, window area, opaque
  wall area, roof area, and exposed floor area;
- wall, roof, floor, and window U-values;
- the component UA terms;
- a thermal-bridge adder;
- the final `UA_total_W_K` copied back into the runtime archetype table.

The geometry assumptions are deliberately simple:

- detached houses: two storeys, all external walls exposed;
- semi-detached houses: two storeys, 75% of walls exposed;
- terraced houses: two storeys, 50% of walls exposed;
- apartments: one dwelling-storey equivalent, 35% wall exposure, and 25% roof
  and floor exposure.

This makes the heat-loss coefficient defensible and inspectable, but not final.
The next improvement would be to split as-is archetypes by construction period
or EPC band and derive external envelope areas from a richer building-stock
geometry model.
